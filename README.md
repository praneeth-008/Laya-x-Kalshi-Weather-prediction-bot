# Laya × Kalshi Weather Prediction Bot

Research project investigating whether probabilistic neural networks can identify information not already reflected in prediction-market prices.

## Initial Experiment

Predict NYC next-day maximum temperature using:

- Numerical weather forecasts
- Current weather observations
- Forecast revisions
- NWS Area Forecast Discussions
- Laya probabilistic model

Model-generated probabilities will eventually be compared against contemporaneous Kalshi market probabilities.

## Research Pipeline

Data → Baseline → Base Laya → Calibration → Fine-tuning → Backtest → Live System

## Current Stage

Building the historical point-in-time dataset for NYC temperature markets.
